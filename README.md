# TOIS

PET-проект торговой информационной системы на Java 21, Spring Boot и PostgreSQL. Интерфейс для сотрудников - настольный клиент на JavaFX.

## Бизнес-логика

- **Торговые точки.** Система хранит ассортимент, цены и остатки отдельно по каждой точке. Сотрудники назначаются на точки и секции.
- **Продажи и снабжение.** Продавец регистрирует продажи и оформляет заявки на поставку. Менеджер ведёт заказы поставщикам, принимает поставки и оформляет перемещения товаров между точками.
- **Отчётность.** Доступны отчёты по продажам, оборачиваемости, рентабельности и работе торговых точек.
- **Доступ.** Администратор управляет учётными записями, ролями и разрешениями. Операции продавца ограничены его назначениями.

## Слои приложения

JavaFX-клиент обращается к REST API. Контроллеры проверяют входные данные, сервисы выполняют операции учёта. Для работы с данными используются Spring Data JPA и PostgreSQL, для отчётности - SQL через Spring JDBC. Flyway отвечает за инициализацю схемы и начальные данные.

## Локальный запуск

Для бэкенда нужны Docker и Docker Compose. Для клиента - JDK 21 и графическая среда. Команды выполняются из корня репозитория.

### Бэкенд

Перед первым запуском необходимо задать `TOIS_DB_PASSWORD`, `TOIS_ADMIN_PASSWORD` и `TOIS_JWT_SECRET`. Секрет JWT должен содержать не менее 32 байт; для локального запуска можно использовать случайное значение в Base64. Секрет и пароли не хранятся в репозитории.

```powershell
$bytes = New-Object byte[] 32
$random = [System.Security.Cryptography.RandomNumberGenerator]::Create()
$random.GetBytes($bytes)
$random.Dispose()
$env:TOIS_JWT_SECRET = [Convert]::ToBase64String($bytes)
$env:TOIS_DB_PASSWORD = Read-Host 'Local database password'
$env:TOIS_ADMIN_PASSWORD = Read-Host 'Local administrator password'
docker compose up --build -d
```

API доступен на [localhost:8081/api](http://localhost:8081/api). При первом запуске Flyway создаёт схему в отдельном томе Docker; приложение создаёт администратора `superadmin` с паролем из `TOIS_ADMIN_PASSWORD`. Если аккаунт уже существует, запуск не меняет его пароль. Исторический каталог `Postgres/postgres_data` не подключается.

### Клиент

```powershell
Set-Location toisClient
.\gradlew.bat run
```

На Linux и macOS команда запуска из каталога клиента - `bash ./gradlew run`. При нестандартном порте бэкенда адрес API можно задать переменной `TOIS_API_URL`, включая суффикс `/api`.

Вход администратора - `superadmin`. Для работы под продавцом или менеджером нужна учётная запись с соответствующей ролью и привязкой к сотруднику. Новая база не содержит торговых документов.

## HTTP API

Вход выполняется через `POST /api/auth/login`. Защищённые запросы принимают JWT в заголовке `Authorization: Bearer <token>`. Маршруты разделены по рабочим областям: `/api/admin`, `/api/manager`, `/api/seller`. Списки менеджера и администратора принимают `page` и `size`; первая страница имеет номер 0.
